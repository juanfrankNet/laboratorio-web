Windows (Alt Codes)

Mantén Alt y escribe el número en el teclado numérico. Prueba con el 0 inicial si falla.

macOS (Option)

Usa Option ⌥ + tecla. Para códigos hex, activa "Entrada Unicode" en ajustes de teclado.

Linux (Unicode)

Pulsa Ctrl+Shift+U, escribe el código Hex y pulsa Enter.
